## Kestrel Desktop 0.7.0

- publishes the signed and notarized macOS arm64 application for macOS 13 or later
- packages Desktop, Local Core, and the local PGlite database into one application
- provides manual update checking, download, and explicit restart-and-install
- blocks update installation while Desktop or Local Core work is active without cancelling that work

[Download Kestrel Desktop 0.7.0](https://github.com/LumiCorp/kestrel/releases/tag/desktop-v0.7.0) or read the [installation guide](/desktop/install).

## Public packages 0.7.0

- introduces the required explicit `assistantText` terminal-result field
- documents Kestrel One as the hosted product centered on Threads and Projects
- documents organization-scoped model access and managed model deployments
- aligns CLI, Runtime, Protocol, SDK, Memory, Next.js, AI SDK, Observability, and Workspace Skills around one stable package line
- organizes guidance around Desktop, Kestrel One, building applications, and operating deployments

Desktop and the public packages happen to share the `0.7.0` version number, but their release gates and artifacts remain independent. Kestrel One remains invitation-managed.

Read [Upgrading to 0.7](/build/upgrading-to-0-7) before changing a consumer.
