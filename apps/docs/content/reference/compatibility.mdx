Use the `0.7.0` package line together across Runtime, Protocol, SDK, and adapters. The signed public Desktop release is also `0.7.0`, but Desktop and Kestrel One remain products with independent release channels; Kestrel One is invitation-managed. Do not infer a product artifact version from the npm package line.
