Use the `0.7.0` package line together across Runtime, Protocol, SDK, and adapters. Desktop and Kestrel One are products with independent release channels: the signed public Desktop remains `0.6.0`, while Kestrel One is invitation-managed. Do not infer a product artifact version from the npm package line.
