## Requirements

Use macOS 13 or later on a Mac with Apple silicon. You need permission to install an application in Applications and to open the project folders you give Kestrel. Desktop includes Local Core; you do not need to configure a separate database or runner for the first local task.

## Install the application

1. Open the unified [`v0.8.0` release](https://github.com/LumiCorp/kestrel/releases/tag/v0.8.0).
2. Download `Kestrel-0.8.0-mac-arm64.dmg` and its checksum.
3. Verify the checksum, open the DMG, and move Kestrel to Applications.
4. Open Kestrel from Applications.

## Verify the application

macOS should accept the Developer ID signature and notarization. Confirm the application reports `0.8.0`. Stop if the checksum, signer, version, or release revision does not match the published record.

## Upgrade from 0.7

Quit the existing application and replace it in Applications. Do not remove its data. The upgrade preserves provider settings, Keychain credentials, projects, sessions, conversations, Mission Control records, and Local Core persistence.

## Update Desktop

Kestrel 0.8.0 is a manual installation and does not move stable OTA metadata. Read [Update Kestrel Desktop](/desktop/updates) before replacing an existing installation.

## If the application does not open

Confirm the platform and checksum, reopen the DMG, and inspect the exact Gatekeeper or LaunchServices message. Do not disable macOS security controls globally or delete application data. Continue with [Desktop troubleshooting](/desktop/troubleshooting) and collect the version, warning, timestamp, and support bundle.
