Kestrel is an open-source agent platform with a desktop app, shared team workspaces, a CLI/TUI, and a TypeScript SDK. Use it with the model you choose to build software, conduct research, analyze data, and create reports, spreadsheets, presentations, and other files.

## Product surfaces

- **Kestrel Desktop** is a local AI agent for projects on your computer. It works with the files and tools in a folder you open.
- **Kestrel One** is the team workspace. Projects group members, Threads, instructions, files, Knowledge, Apps, and execution Environments.
- **CLI/TUI** provides interactive terminal work, scripts, automation, and direct runtime controls.
- **TypeScript SDK** lets applications start, stream, resume, and inspect local or remote Kestrel runs.

## Runtime and protocol

Kestrel Runtime is the agent harness underneath every surface. It runs model and tool steps and records sessions, events, artifacts, waiting, cancellation, recovery, and replay.

Local Core hosts the runtime on a user's computer. The runner service hosts it behind an authenticated network boundary. Both expose the same Execution Protocol for commands, streams, events, and terminal results.

## Use only what you need

Start with Desktop for local projects, Kestrel One for shared team work, the CLI/TUI for terminal workflows, or the SDK for an application integration. The products release independently, so check [Release status](/start/release-status) for current availability and versions.
