Open a project you care about and give Kestrel a real outcome to work toward. Desktop can inspect the material, use approved tools, change files, create new ones, and show you what it did without separating the work from the project.

Use it to build software, investigate a question, analyze data, or create a report, spreadsheet, presentation, or other file. The project, conversation, active run, and outputs remain together in one application.

## Start with an outcome

Choose the model you want to use, open the folder where the work belongs, and describe what you want to have when Kestrel finishes. Follow the conversation and activity while Kestrel reads files, uses tools, and produces the result.

### Give Kestrel the project

Each session belongs to a local workspace. Kestrel starts with the project files, and the requests, changes, and results remain attached to that workspace instead of becoming a disconnected chat.

### Leave and come back

Close the application and return to the same session later. The earlier conversation, completed runs, and current project remain available, so you can continue without explaining the work again.

### Know where things stand

See whether the run is active, completed, waiting for you, cancelled, or failed. Review the answer, generated files, recent activity, and recorded outcome instead of relying on the last visible message.

### Step in when the work needs you

Inspect, steer, stop, resume, retry, or recover the existing run. Your intervention stays with the session instead of forcing you to discard the work and begin again.

## What people use Desktop for

Use Desktop when the result belongs in a project rather than only in a chat window. For example:

- investigating a bug and keeping the findings with the project
- planning and carrying out a change that touches several files
- analyzing a dataset and saving the result with its source material
- producing a report, spreadsheet, or presentation from project files
- reviewing what changed, what was produced, and what still needs attention
- correcting course when a task waits, fails, or heads in the wrong direction

## Start with one real project

[Download Kestrel Desktop 0.7.0](/desktop/install), connect a model, and open a project you already understand. Ask for one useful outcome, review what Kestrel produces, and then return to the same session when you have the next task.
