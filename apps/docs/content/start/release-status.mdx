Kestrel `0.8.5` is one coordinated release across the runtime, nine public packages, CLI/TUI, Desktop, and Kestrel One source. Packages are Stable; Desktop and Kestrel One are Beta. Packages come from npm, Desktop is available as a signed download and through its stable updater, Kestrel One source comes from the tag, and Lumi hosting requires an organization invitation.

Runtime, Protocol, SDK, Memory, adapters, and clients must use the exact matching 0.8 line. Hosted operation separately records Vercel deployment and migration results and the selected tag and provider result for each manually changed runtime target.

## Install and access

- Install the [CLI/TUI](/cli/install) with Node.js 22 on macOS arm64 or Linux x64.
- Install [Desktop](/desktop/install) on macOS 13 or later on Apple silicon, or update a signed 0.7.0 or 0.8.0 installation through the stable channel.
- Get [Kestrel One source](/kestrel-one/source-and-hosting) from `v0.8.5`.
- Use an organization invitation for the Lumi-hosted Kestrel One service.
- Pin all installed Kestrel packages, including Runtime/CLI, to `0.8.5`.

## Compatibility

Kestrel 0.8 does not add 0.7 wire or SDK compatibility shims. Upgrade the full integration boundary together and follow [Upgrading to 0.8](/build/upgrading-to-0-8).

## Platform limits

Desktop release support is macOS arm64. CLI release support is macOS arm64 and Linux x64. Other platforms are not release-verified for 0.8.

## Release evidence

Use the unified [`v0.8.5` GitHub release](https://github.com/LumiCorp/kestrel/releases/tag/v0.8.5), published checksums, npm registry metadata, [release notes](/reference/releases), and hosted build identity. Do not treat one artifact as proof that another surface passed its gate.
