Kestrel `0.8.0` is one coordinated Beta release across the runtime, public packages, CLI/TUI, Desktop, and Kestrel One source. Distribution and access remain different: packages come from npm, Desktop is a manual signed download, Kestrel One source comes from the tag, and Lumi hosting requires an organization invitation.

Runtime, Protocol, SDK, Memory, adapters, and clients must use the exact matching 0.8 line. A hosted deployment also records its source revision, migrations, worker revisions, and immutable image digests.

## Install and access

- Install the [CLI/TUI](/cli/install) with Node.js 22 on macOS arm64 or Linux x64.
- Install [Desktop](/desktop/install) manually on macOS 13 or later on Apple silicon.
- Get [Kestrel One source](/kestrel-one/source-and-hosting) from `v0.8.0`.
- Use an organization invitation for the Lumi-hosted Kestrel One service.
- Pin public package installs to `0.8.0`.

## Compatibility

Kestrel 0.8 does not add 0.7 wire or SDK compatibility shims. Upgrade the full integration boundary together and follow [Upgrading to 0.8](/build/upgrading-to-0-8).

## Known deferrals

Desktop 0.8.0 does not move stable OTA metadata. The first OTA proof is a controlled `0.8.0` to `0.8.1` patch. Desktop release support is macOS arm64; CLI release support is macOS arm64 and Linux x64. Other platforms are not release-verified for 0.8.

## Release evidence

Use the unified [`v0.8.0` GitHub release](https://github.com/LumiCorp/kestrel/releases/tag/v0.8.0), published checksums, npm registry metadata, [release notes](/reference/releases), and hosted build identity. Do not treat one artifact as proof that another surface passed its gate.
