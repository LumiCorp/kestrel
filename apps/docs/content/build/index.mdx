Create an agent in TypeScript and point it at a local or remote Kestrel runtime. Start with one server-side request, inspect the terminal result, and then add streaming, memory, routes, waiting, and observability as your application needs them.

The Build journey follows the shipped Reference agent throughout. Every guide extends the same agent, profile, and session model, so you keep working code at each step instead of assembling disconnected examples.

## Start building

1. [Build your first agent](/build/building-your-first-agent) and inspect its terminal result.
2. [Stream the next request](/build/running-your-first-streamed-request) without changing session continuity.
3. Add [explicit session memory](/build/adding-session-memory).
4. Expose the agent through [Next.js routes](/build/integrating-with-nextjs).
5. Handle [waiting, resume, and cancellation](/build/waiting-resume-and-cancellation).
6. Add [observability](/build/adding-observability) before production operation.

Begin with [Build your first agent](/build/building-your-first-agent). Run it successfully before adding the next integration capability.

## Handle results correctly

Before shipping, read [Protocol and results](/build/protocol-and-results). A terminal result always contains `assistantText: string | null`; human-facing text is not inferred from structured finalized data. Use [Runner events](/build/runner-events) for the exact streaming vocabulary and [Upgrading to 0.7](/build/upgrading-to-0-7) for compatibility changes.
